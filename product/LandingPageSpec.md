# AlphaPulse Landing Page UX/UI Spec v1.0

## Основная идея

Пользователь должен почувствовать:

> "Наконец-то кто-то отсеивает весь этот шум за меня."

Не:

> "Сейчас я разбогатею."

Не:

> "Срочно покупай подписку."

А:

> "Я могу расслабиться, пока система работает."

---

# Стиль бренда

Ассоциации:

- спокойствие;
- интеллект;
- уверенность;
- аналитика;
- премиальность.

# Анимации

Очень аккуратные.

Использовать:

- Framer Motion;
- fade;
- blur;
- slow float.

Не использовать:

- прыжки;
- мигание;
- агрессивные эффекты.

---

# Mobile UX

Проверяем:

- iPhone SE;
- iPhone 16 Pro Max;
- Android.

Hero должен помещаться без скролла.
