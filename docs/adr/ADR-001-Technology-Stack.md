# ADR-001

Title:
Technology Stack Selection

Status:
Accepted

Date:
2026-07

---

## Context

AlphaPulse requires:

- fast development
- low infrastructure cost
- strong AI ecosystem support

---

## Decision

Frontend:

Next.js

Backend:

FastAPI

Database:

PostgreSQL

Cache:

Redis

AI:

OpenAI API

---

## Consequences

Positive:

- fast MVP
- large talent pool
- mature ecosystem

Negative:

- Python performance limitations
- dependence on OpenAI
